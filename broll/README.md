# پوشه‌ی فوتیج (B-roll)

هر کلیپی که مجوز استفاده‌اش را داری (گل‌ها، خلاصه‌های رسمی، مصاحبه‌ها، کنفرانس خبری) را اینجا بگذار و اسم فایلش را
در `stories.json` هر خبر، در فیلد `"broll"` بنویس. مثال:

```json
{
  "id": "arsenal-anfield",
  "broll": "arsenal-liverpool-havertz.mp4"
}
```

نکته‌های مهم

- فایل‌ها در گیت کامیت نمی‌شوند (`.gitignore`)؛ فقط روی سیستم خودت می‌مانند.
- کلیپ هرچه کوتاه‌تر (۳–۵ ثانیه از هر صحنه) بهتر؛ اگر کوتاه‌تر از سگمنت باشد، ایجنت خودش لوپ می‌کند.
- هر فرمتی که ffmpeg بخواند قبول است (mp4/mov/mkv/webm). نسبت تصویر مهم نیست؛ خودکار برش ۹:۱۶ می‌شود.
- اگر برای خبری کلیپ نگذاری، به‌جای آن «کارت خبری» با تیتر، فکت‌ها و منبع ساخته می‌شود — همه‌چیز باز هم قابل انتشار است.
- مجوز: فقط فوتیج رسمی لیگ/باشگاه/فدراسیون یا آرشیو دارای لایسنس. لوگوی منبع را روی تصویر نگه دار.
  فایل `out/publish-kit/sources.md` برای کردیت‌دادن ساخته می‌شود.
